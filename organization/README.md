# 组织架构

本目录归档本仓库的部门层级、职责边界和跨部门接口。最高效力规则仍由
[`../DIRECTIVE.md`](../DIRECTIVE.md) 授权；任何组织架构调整都必须先同步写入
`DIRECTIVE.md`，本目录不得覆盖或降低其中的要求。

## 架构图

```text
总控
├── 资源获取分析司
│   └── 资源跟踪与钦定清单：resources/registry.json
├── 定期巡检司
│   └── 巡检任务执行方案处
│       └── 巡检登记与台账：inspection/registry.json、inspection/ledger/
└── 模块2：视频处理部
    ├── 素材接收组
    ├── 字幕时间精确刻录司
    ├── 字幕区判定组
    ├── 刻录渲染组
    └── 质检交接组
```

## 职责接口

- **资源获取分析司**维护资源清单、采集器映射与资源变化；不负责视频字幕刻录。
- **定期巡检司**负责巡检制度、最小可巡检单元、证据与异常闭环。
- **模块2：视频处理部**只接收上游已经选定的视频和字幕任务；不得自行替代上游
  选择来源、判定资源重要性或更改巡检结论。
- 模块2的五个职责单元及精度、画面处理要求，见
  [`module-2-video-processing.md`](module-2-video-processing.md)。

## 档案与实现状态

本目录是组织职责档案，不代表其中列出的每个目标模块均已实现。模块2的职责映射、
当前代码位置和未完成要求必须分开说明；不得仅凭架构登记宣称功能已上线。
