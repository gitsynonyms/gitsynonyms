独立运行 CLI

不依赖总统监测项目，可直接从技能仓库运行研究引擎。需要 Python 3.12+；先运行 preflight，并按它的输出选择解释器。

安装为独立技能

Copilot、Codex、Cursor、Gemini CLI 等 Agent Skills 宿主可用 Skills CLI 安装：

npx skills add mvanhorn/last30days-skill -g

安装后，在支持该技能的助手中输入 /last30days 你的研究主题。技能会按主题和可用凭据选择数据源；未配置的数据源可能不可用。

本网页不会代替你运行研究或保存凭据。上面的命令在你自己的技能宿主或终端中执行；这里的 Last30Days 演示与总统监测保持独立。
