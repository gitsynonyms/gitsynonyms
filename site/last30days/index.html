在 AI 助手中使用

独立运行 CLI

可直接从技能仓库运行研究引擎。需要 Python 3.12+；先运行 preflight，并按它的输出选择解释器。

页面会读取“最新成片”中最近归档的视频和英文字幕。默认研究主题为视频标题；你也可以查看字幕后换成视频里出现的人物、某条新闻或具体议题，再让 Last30Days 查找过去 30 天的公开讨论。频道刚上传但尚未归档的视频会在字幕站更新后显示。

安装 Last30Days 技能

Copilot、Codex、Cursor、Gemini CLI 等 Agent Skills 宿主可用 Skills CLI 安装：

npx skills add mvanhorn/last30days-skill -g

安装后，在支持该技能的助手中输入 /last30days 你的研究主题。技能会按主题和可用凭据选择数据源；未配置的数据源可能不可用。

本网页不会代替你运行研究或保存凭据。上面的命令在你自己的技能宿主或终端中执行；视频部分只是提供一个真实选题入口，并不把 Last30Days 接入白宫视频监测流程。
